# yb-cascader

Skyline 独立多级数据选择组件，复用 yb-flyout 的定位、portal 和整体开合。

- `options`: `{ id, label, disabled?, children? }[]`；最多十级，第十级按叶子处理；`themeStyle` 透传主题。
- `open(anchorRect, boundaryRect?)` 打开；`back()` 逐级返回；`close()` 关闭整体；`select` 返回 `{ value, item, path: [{id,label}] }`；`close` 在整体退场完成时触发。
- 直接复用模型选择器的触发行、列表、圆角、玻璃背景和阴影样式。子层保留上级选中数据作为触发行（不是新增标题），点击触发行逐层收起；点击遮罩或透明动画留白直接关闭整个弹窗，卡片内部点击不冒泡到留白；下方分隔线和列表一起展开。
- 展开使用原模型弹窗的 160ms 高度/透明度 timing、spring(0.05, velocity:5, mass:0.8) 放大与父层 inset；原层是兄弟节点，只有直接父层收窄，祖先层不动。收起还原为触发行位置和 100rpx 高度。
- 每层最多5条（根层5条数据，子层100rpx上级触发行加4条110rpx数据），长列表内部滚动；触发行 100rpx。高子层向上增长，较矮子层顶部对齐父层，不额外增加逐层底部偏移。
- 透明外层 640rpx 宽，卡片 400rpx，按触发容器左右位置贴近对应边，边距36rpx；高度为最高卡片加260rpx，并按实际可用视口缩减。留白覆盖原始 spring 峰值，不钳制或更改原动画幅度。定位扣除透明留白，实际卡片紧接触发容器底边，受视口安全边界约束；左侧锚点镜像缩放原点以保留放大空间。
- 保留局部尺寸、动画及玻璃卡片样式，复用主题变量 `--glass-72`、`--text-l1/l2/l3`、`--bg-l3`；不读取 Store、请求或业务状态。
